# Prevention Pattern Library

Jarvis uses a versioned control library so preventive answers build on established practices
instead of relying only on generative intuition.

The initial control families draw from NIST SSDF 1.1, NIST AI RMF, NIST Cybersecurity
Framework 2.0, SLSA, OWASP ASVS, and Google SRE error-budget practice. Source URLs are stored
beside the controls for review. The registry does not copy those standards or claim
certification.

Core controls cover outcomes, evidence, ownership, dependencies, observability, testing,
reversibility, rollback, budgets, and security. Domain tags add AI oversight, software
supply-chain integrity, and reliability controls.

Recommended controls are inputs to design review. They must be tailored to the actual system,
threats, laws, stakeholders, and consequences. Passing a checklist does not prove that a
future problem cannot occur.
