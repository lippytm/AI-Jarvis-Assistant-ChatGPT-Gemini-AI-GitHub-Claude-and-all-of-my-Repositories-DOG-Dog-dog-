# BIG BRAIN Hostinger viability pilot

The program targets 22 platform and 7 private brain identities. `BrainGateway` is an offline mock gateway. It loads identities from an operator-supplied local JSON roster, writes a separate MemPalace database per activated identity, and rejects private-to-platform transfers. The private roster is not committed here. This code does not create 29 active AI agents or autonomous schedules.

The public Hostinger capability matrix distinguishes website inventory, Manual AI Builder, Agentic AI Builder (Horizons), ecommerce, and WordPress AI tools. The 29 × 5 = 145 combinations are **planning possibilities**, with zero authenticated live integrations. Private brains remain isolated from Hostinger by default.

The [current Horizons API index](https://docs.hostinger.com/api-reference/endpoints/horizons/websites)
lists site creation, editing and publication as well as clone, list and get
operations. The hosting API separately documents
[static archive deployment](https://docs.hostinger.com/api-reference/endpoints/hosting/websites/deploy-static-site-archive).
These are documented product capabilities, not evidence that the target account
has the relevant product, permissions or a working connection. This repository
implements only bounded read-only hosting website inventory in this adapter;
no builder creation, editing, publication or spending has been activated.
The inventory tests inject responses and do not authenticate to Hostinger.

## Activation criteria

1. Load the approved roster from a private runtime location; do not commit it.
2. Verify the intended Hostinger account and site with a privately stored token through the read-only inventory endpoint.
3. Identify the actual product for `aievolutionaryevolutions.com` (Website Builder,
   WordPress, custom/static, Node or Horizons), verify DNS and privately inventory
   the pages, forms, scripts and redirects before choosing a draft handoff.
4. Check evidence, costs, permissions, rollback, and the owner approval gate before a live workflow.

The proposed `/funding-readiness` gateway and a separate inventory-review mapping
are described in [the Hostinger mapping plan](PROPOSED_HOSTINGER_WORKFLOW_MAPPINGS.md).
They are not additional shipping workflows or proof that 29 agents are connected.
